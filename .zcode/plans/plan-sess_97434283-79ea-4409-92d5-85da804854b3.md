## 概述

添加三个新命令行选项：`-x`（proxy 短别名）、`-o`（输出目录，双写不带域名层级）、`-t`（整体超时时间，默认 120s 替代当前硬编码 30s）。

## 改动详情

### 1. `main.go` — 参数解析 + cache config + timeout

**新增变量**（~line 73 附近）：

        os.Exit(1)
    }
    timeoutSecs = n

### 2. `pkg/fetcher/cache.go` — CacheConfig + 双写逻辑

**CacheConfig 结构体新增 OutputDir 字段**：
```go
type CacheConfig struct {
    Enable       bool
    BaseDir      string
    WriteEnabled bool
    OutputDir    string // 非空时，所有 Save 操作额外写一份到此目录（不带域名层级）
}
```

**新增辅助方法 `getOutputPath`**：
计算 -o 目录下的路径（不含域名层级）：
```go
func (c *CacheConfig) getOutputPath(subDir, urlPath string) string {
    normalizedPath := NormalizePathForFile(urlPath)
    return filepath.Join(c.OutputDir, subDir, normalizedPath)
}
```

**新增辅助方法 `writeFileBoth`**（或在每个 Save 方法末尾追加写入）：
```go
// writeFileOutput 在 OutputDir 非空时，将内容额外写入一份到输出目录（不带域名层级）
func (c *CacheConfig) writeFileOutput(subDir, urlPath string, content []byte) {
    if c.OutputDir == "" {
        return
    }
    outPath := c.getOutputPath(subDir, urlPath)
    dir := filepath.Dir(outPath)
    if err := os.MkdirAll(dir, 0755); err != nil {
        return
    }
    os.WriteFile(outPath, content, 0644)
}
```

**修改 4 个 Save 方法**，在 `WriteFile` 成功后追加一次 `writeFileOutput`：
- `SaveToCache` — `writeFileOutput(subDir, urlPath, content)`
- `SaveMetadata` — `writeFileOutput("metadata", urlPath+".json", metadata)` 或 meta.json 情况
- `SaveDataURI` — `writeFileOutput("source_map", urlPath+".map", content)`
- `SaveSourceFile` — 输出目录用 `filepath.Join(c.OutputDir, "sources", cleanPath)`，路径不拍平

**Load 方法不变**：OutputDir 只影响写入，读取仍走缓存目录。

## 不受影响的行为

- 默认无 `-o`：OutputDir 为空，不双写，行为完全不变
- `-x`：只是 `--proxy` 的别名，值传递路径完全不变
- `-t`：默认 120s 比原来 30s 更合理，用户可自定义
- 所有 Load 方法不变，OutputDir 只影响写入
